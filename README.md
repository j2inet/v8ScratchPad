# V8 Scratchpad


In exploring v8 integration, I decided to make this scratch pad project. This project doesn't have a functional 
end-goal in mind. Instead, it is just a space in which I can test syntax and random function calls. I may start 
to add comments in case someone else wants to look up how to perform some task in v8.
